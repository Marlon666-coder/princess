# Letakkan model karakter di sini

Taruh file model 3D kamu (format **`.glb`** paling disarankan) di folder ini.

## Penamaan file

Pilih salah satu pola:

**A. Satu model berisi pasangan (cowok + cewek jadi satu):**
- `couple.glb`

**B. Dua model terpisah:**
- `boy.glb`  (karakter cowok)
- `girl.glb` (karakter cewek)

## Dari mana dapat model gratis?

- Sketchfab (https://sketchfab.com) — filter **Downloadable** + **Free**, export **GLB**
- Quaternius (https://quaternius.com) — karakter lowpoly gratis
- Ready Player Me (https://readyplayer.me) — bikin avatar sendiri, export GLB

## Catatan
- Kalau model-nya "rigged/animated", Kiro akan memutar animasi idle-nya.
- Kalau tidak ada animasi, Kiro menambahkan gerakan halus (bernapas/goyang).
- Format `.gltf` + `.bin` + texture juga bisa, tapi `.glb` (satu file) paling gampang.
